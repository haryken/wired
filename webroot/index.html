⚡ Hồ sơ hiệu năng

Cách dùng
  1. Thường — ổn định, ít nóng. (Regular — stable, cooler.)
  2. Cân bằng — giữa ổn định và tốc độ. (Balanced — middle ground.)
  3. Hiệu năng cao — SDK nhanh hơn, máy có thể nóng. (Performance — faster SDK, may overheat.)
  4. Chọn xong có thể cần khởi động lại robot. (A restart may be required after changing.)

Đừng để Hiệu năng cao lâu nếu robot nóng bất thường. (Avoid long Performance mode if the robot runs hot.)

🎛 Engine đánh thức

Chọn engine
  • Picovoice — mở khóa Từ đánh thức + Độ nhạy.
  • Hey Vector (THF) — Sensory stock; mở khóa Giọng THF (model giọng / độ nhạy wake).

Chọn radio rồi bấm Lưu engine + restart để áp dụng. Tile khóa/mở phía trên chỉ đổi sau khi lưu (đổi radio chưa lưu không ảnh hưởng).

THF đang bật — chỉnh model giọng / độ nhạy wake ở mục Giọng THF (không phải đổi ngôn ngữ robot).

Use Giọng THF for accent/wake sensitivity — not UI language.

🎤 Từ đánh thức tùy chỉnh

Chỉ dùng với engine Picovoice. Đang THF — mục này bị khóa.

Cách dùng
  1. Nhập từ muốn dùng — ít nhất 2 âm tiết, 5+ chữ cái. (At least two syllables, 5+ letters.)
  2. Bấm Tạo từ đánh thức — robot sẽ tải model rồi khởi động lại. (Generate — installs model then restarts.)
  3. Muốn về “Hey Vector” mặc định Picovoice: bấm Về mặc định. (Revert restores default .ppn.)

Trong lúc khởi động lại, đợi trang báo xong rồi mới gọi. (Wait until restart finishes before calling the robot.)

📶 Độ nhạy từ đánh thức

Chỉ dùng với engine Picovoice. Đang THF — mục này bị khóa.

Cách dùng
  1. Kéo thanh hoặc gõ số (mặc định 0.45). (Drag or type; default 0.45.)
  2. Cao hơn = dễ đánh thức hơn (dễ nhầm tiếng ồn). (Higher = easier wake, more false triggers.)
  3. Thấp hơn = khó đánh thức hơn (ít nhầm). (Lower = harder wake, fewer false triggers.)
  4. Bấm Đặt — robot khởi động lại để áp dụng. (Set — robot restarts to apply.)

Khoảng hợp lệ: 0.001 – 0.999. Chỉ Picovoice. (Picovoice only.)

🗣 Giọng THF

Chỉ dùng với engine Hey Vector (THF). Đang Picovoice — mục này bị khóa.

Không phải đổi ngôn ngữ. Mỗi lựa chọn là model Sensory khác nhau — ảnh hưởng độ nhạy / dễ bắt “Hey Vector” theo giọng nói.

★ en-AU thường nhạy nhất với người Việt (khuyến nghị). Các model khác thường cần phát âm “Hey Vector” chuẩn tiếng Anh hơn.

Accent profile for wake detection — not robot language. ★ en-AU recommended for Vietnamese speakers.

💜 Xiaozhi AI

Chế độ nghe lệnh

Chọn bên dưới — đổi là áp dụng ngay (không cần Lưu). Robot khởi động lại cloud vài giây.

💜 Xiaozhi

  • Nói chuyện tự nhiên (VN/EN) với cloud.
  • LLM / MCP điều khiển robot (cube, blackjack…).
  • Hiện khối cấu hình Xiaozhi bên dưới.

🎙 Vosk

  • STT offline trên robot (thường tiếng Anh).
  • Xiaozhi cloud tắt; ẩn cấu hình Xiaozhi.
  • Xem cụm lệnh ở tab Lệnh thoại.

Cấu hình Xiaozhi

  1. Máy chủ OTA: lần đầu để mặc định https://api.tenclass.net/. Đã lưu rồi thì giữ nguyên.
  2. WebSocket: ô xám — hệ thống tự lấy từ OTA, chỉ xem, không cần sửa.
  3. ID thiết bị / client: lần đầu để trống để robot tự tạo MAC / UUID.
  4. Lấy mã 6 số: bấm Lưu & kích hoạt. Robot hiện mã (hoặc báo đã ghép).
  5. Ghép trên web: vào xiaozhi.me → tạo agent → cấu hình agent → thêm mã 6 số vào agent vừa tạo.
  6. Muốn cấu hình lại / lấy mã mới: xóa hết ô ID thiết bị (MAC) hiện tại → bấm lại Lưu & kích hoạt → làm tiếp bước 5 với mã mới.

🎙 Lệnh thoại

Hai cách dùng
  1. Xiaozhi bật — nói tự nhiên; AI hiểu rồi điều khiển robot (MCP). Cấu hình ở tab Xiaozhi.

Cách 1 — Xiaozhi ON
  1. Tab Xiaozhi: bật → Lưu → đã kích hoạt xiaozhi.me.
  2. Hey Vector → nói ý muốn bằng tiếng Việt hoặc Anh (ví dụ “lăn khối lập phương”, “chơi blackjack”).
  3. Robot trả lời bằng TTS Xiaozhi rồi làm hành động (có thể im mic đến khi bạn wake lại sau self-control).

🃏 Chơi bài — Blackjack

Nói “chơi blackjack” / “play blackjack”. Trong ván, robot hỏi bằng giọng máy (Acapela) và nghe yes / no (Vosk tạm thời):

  • Bắt đầu: “chơi blackjack”, “play blackjack”, “đánh bài”
  • Khi hỏi muốn thêm bài? (hit): nói yes = rút thêm · no = dừng (stand)
  • Hết ván, hỏi chơi round mới?: yes = ván mới · no = thoát
  • Cũng nhận: hit / stand / another card (tiếng Anh)

Trong blackjack không chat Xiaozhi; trả lời ngắn yes/no khi mic mở. Hết game tự về Xiaozhi nếu đang bật.

🎮 Điều khiển (beta)

Cách dùng
  1. Bấm Chiếm quyền trước — lúc đó mới lái / tay / đầu / gương / micro được.
  2. Dùng pad / camera khi đang chiếm quyền. Bật Micro để nói qua loa robot.
  3. Xong thì tắt micro và bấm Nhả quyền — robot mới về trạng thái tự nhiên / Xiaozhi.
  4. Muốn điều khiển khác mạng: bật Ngoài mạng → copy link HTTPS → mở trên 4G/Wi‑Fi khác.

Micro cần trang HTTPS: mở https://IP-robot:8443 — HTTP bị trình duyệt chặn mic (Meet vẫn được vì là HTTPS).

Link ngoài mạng hết hạn sau ~2 giờ; ai có link đều điều khiển được — tắt khi xong.

Camera tắt — bật switch bên dưới hoặc Chiếm quyền.

Giữ để chạy — giữa = dừng hết.

🗣 Robot nói

  1. Cần Chiếm quyền trước.
  2. Nhập câu → Gửi — Vector nói bằng giọng máy.

🔊 Phát âm thanh

  1. Chọn file .wav — trình duyệt resample 8 kHz mono rồi gửi.
  2. Nghe thử nếu muốn, rồi Gửi file (cần Chiếm quyền).
  3. Hoặc bật switch Micro phía trên camera để nói trực tiếp qua loa robot.
